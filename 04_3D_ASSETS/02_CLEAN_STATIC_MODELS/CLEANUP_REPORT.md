# HALGAN static Blender cleanup delivery

22/22 designs have reviewed static cleanup versions in this folder. Each has an editable native `.blend`, current `.glb` and `.fbx`, materials and validation evidence. REF008 has two additional LOD variants. No further Tripo credits were used.

The boxing ring was rebuilt with continuous ropes, seated corner pads/turnbuckles, canvas/apron, supports and steps. The framed artwork was rebuilt as a flat image panel, straight frame and flat backing using the actual reference artwork. REF008 was reduced from 1,950,508 to 24,000 triangles, with 12,000 and 4,000 triangle variants. Fighter source silhouettes, faces and clothing were retained while noise, materials, scale and pivots were cleaned. REF056's gold waistband facing has verified clearance; the glove has an authored wrist socket.

REF044 and REF118 were rebuilt as original connected garment meshes because their generated underarm surfaces remained visibly damaged. They now have connected sleeve roots/hood/torso, open cuffs, fabric thickness/lining, satin materials, reference-specific facings, sash and draped ties. Superseded generated versions remain in the relocated working archive; they are excluded from this delivery manifest.

Validation passed for 24 current native/GLB/FBX variants. Current GLB front/rear renders were reviewed against the source references; geometry counts and bounds agreed on reimport, and materials resolved. All 22 original export archives, 22 original native handoffs and 22 reference-image hashes match their baseline. Historical evidence and original hashes were preserved across the external folder relocation.

These are static cleanup deliveries. Character-specific clothing/glove fit, rigging/weights, animation deformation, Unity integration and Android/device validation remain PENDING. Inherited generated facial/hair likeness is simplified; exact photographic reproduction is not claimed. No approved Unity package was changed for this Tripo set.
